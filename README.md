## About Me

> **I am a Computer Science graduate passionate about building intelligent, scalable applications that solve complex problems across diverse domains.**

* **Education:** Recent BSCS graduate with a focus on software engineering and applied systems.
* **What I Build:** I specialize in full-stack and mobile development, creating end-to-end platforms that connect intuitive user interfaces with robust backends and live hardware/IoT telemetry.
* **AI in Action:** I enjoy integrating intelligence into applications to handle messy, real-world data. My experience ranges from training custom object detection models and running time-series analysis to integrating cloud-based AI services into smart, data-driven tools.
